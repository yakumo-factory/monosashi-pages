# 松江市統計レポート — 物差し

松江市が公開する統計情報を、**市民が自分のまちを自分で測るための材料**にして届けています。

**物差し — 測る道具は渡す、当てる先は市民が決める。**

→ **https://yakumo-factory.github.io/monosashi-pages/**

このリポジトリは**公開用**です。生成されたレポートの HTML だけが置いてあります。

## 何が読めるか

町丁ごとの人口・世帯数・年齢構成の推移。**2007年4月から2026年7月までの232か月**を、
月ごとの記録から通して並べています。

| | |
|---|---|
| 町を見る | 町ごとの推移／町どうしの増減 |
| 地区を見る | 地区の比較（人口・世帯数・1世帯あたり・老年人口の割合） |
| 人口の中身を見る | 年齢構成の推移／1世帯あたりの人数／外国人住民 |

**その月に実在する町を全部載せています。** 「全期間そろう町」だけに絞ると、編入で後から
加わった町が黙って落ちます（実測で25町・市の 8.0%）。**自分の町が見つからない人を作らない**
ことを優先しました。比較の起点は、町ごとの記録が始まった月です。

**データ元が正本です。** このレポートが古くなったとき、正しいのはデータ元の側です。
**生データそのものは再公開していません**——どちらが正しいか分からなくなるのを避けるためです。

## 数値がどう作られているか

**機械が決められた手順で読み、機械が確かめています。**

- 統計表（`.xls`）を**決定論的に読みます**。人が目視で数値を書き写したり、直したりしません
- 読んだ結果に**5本の照合**を掛けます——2系列の相互検証／町丁の和と総合計行／年齢3区分と
  総人口／地区の被覆／地区の人口と町丁の和。あわせて、**既知の例外の登録が空振りして
  いないか**を見る検査を1本置いています
- レポートの本文に**手書きの固定値を書きません**。文中の件数も数も、データから導いています
  ——書き写すと、月が増えた瞬間に嘘になるからです
- **図には数値ラベルを載せません。** 正確な値は併置した数表が持ちます。図は形と大小、
  表は正確さ、と役割を分けています

### AI はどこに使われているか

**数値の生成過程に、AI による分類・要約・推定は一切入っていません。**

このレポートを作るプログラムの**開発**には生成AI（Claude）を使っています。しかしそれは
**道具を作る工程**であって、**数値を作る工程ではありません**。動いているのは、人がレビューして
リポジトリに固定した決定論的なプログラムです。

## 確かめていないこと

**機械が確かめているのは「読み方が整合しているか」であって、データ元の数値そのものの
正しさではありません。** 住民基本台帳の値が正しいかを、こちらから検証する手段はありません。

**データ元側の食い違いは、隠さず理由つきで示しています。** たとえば2008年4月は、町丁別の
一覧に1町（3人）が載っておらず合計と食い違います。もう一方の統計表から補えますが、
**補ったことを書かなければ「データ元がそう公表している」と見えてしまう**ので、補った事実を
レポートに書いています。

**制度の変更による段差にも注記を添えています**（東出雲町の編入・住民基本台帳法の改正による
外国人住民の扱いの変更など）。**注記のない折れ線は、制度の変更を人口の増減として読ませます。**

## しないこと

**良し悪しの判断も、理由の説明も、将来の予測もしません。**

増えたことが良いのか、減ったことが悪いのかは、このレポートは言いません。
なぜそうなったかも説明しません。**測る道具を渡すところまでが、このプロジェクトの役目です。**

## 版について

移動します。**過去の版は消しません**——ある時点で何をどう示していたかを、後から辿れるように
するためです。
